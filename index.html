What you get

Small on purpose. No dependencies; the widget is about 15 KB gzipped.

Comments that fade
The author picks a lifetime. Replies never outlast the comment they answer.
No accounts
A name is optional. A password set when posting lets the author edit or delete later.
Little data
No IP, no email, no tracking. Faded and deleted comments stay in your database for moderation.
Replies and reactions
One level of replies, emoji reactions (your own set, or none), author replies with a badge, and optional private comments.
Quote comments
Optional: readers select a sentence to comment on it. Quoted passages can be highlighted, with comment counts in the margin.
Moderation page
Filter by page and state, search, delete in bulk, reply as the author, export JSON or CSV.
Runs on Cloudflare
Workers or Pages Functions, D1, and Turnstile, within the free tier. Optional Slack or Discord webhook.

Use it

Create a D1 database with the files in migrations/ and a Turnstile widget, then:

npm install github:SongYunSeop/iseul

// functions/api/comments.js (Pages Function)
import { createHandler } from 'iseul/server';
export const onRequest = createHandler();

// your page
import { mount } from 'iseul/widget';
import 'iseul/widget.css';
mount('#comments', { siteKey: '<turnstile site key>', lang: 'en' });

Or skip the code: deploy to Cloudflare and paste two lines into your pages. Admin page, client API, webhooks, and options: see the README.
